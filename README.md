# BudsLink Companion

Use Gnome extension [**Bluetooth Battery Meter**](https://github.com/maniacx/Bluetooth-Battery-Meter) as BudsLink Companion

[**Bluetooth Battery Meter**](https://github.com/maniacx/Bluetooth-Battery-Meter) is a companion GNOME Shell extension for the Flatpak application [**BudsLink**](https://github.com/maniacx/BudsLink).
It adds a system tray / panel menu integration to the GNOME panel.
